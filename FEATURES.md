# Функционал проекта

## Стек
Next.js 16 · TypeScript · Supabase (Auth + PostgreSQL) · SCSS Modules · GSAP · Lucide React

---

## Публичные страницы

**Главная (`/`)**
- Hero Slider с 3 слайдами, каждый меняет тему всего сайта (crisis / breakout / recovery)
- Фоновые картинки из `/public`
- Статистика: участники (через RPC), тесты пройдены, рейтинг довольных
- Секция фич, CTA
- Форма заявок на консультацию (сохраняется в Supabase + email через Resend)
- Кнопка "Начать" → `/sign_up` для гостей, `/dashboard` для залогиненных

**Авторизация**
- Регистрация (`/sign_up`) и вход (`/sign_in`) через Supabase Auth
- После входа → `/dashboard`

---

## Личный кабинет (`/dashboard`)
- Прогресс курса (прогресс-бар)
- Психологический паспорт — результаты всех пройденных тестов
- Совет дня (случайный из базы)
- Быстрые действия: Курс, Тесты, Сертификат
- Список уроков с отметкой пройденных
- Карточка сертификата с прогресс-кругами (замок пока не выполнены условия)

---

## Курс (`/course`, `/lesson/[id]`)
- Список модулей и уроков
- Страница урока: картинка/видео, текст, навигация между уроками
- Кнопка "Отметить пройденным" → сохраняется в `user_progress`
- Модалка после прохождения со звёздным рейтингом
- Мобильная фиксированная панель навигации по урокам

---

## Тесты (`/test`, `/test/[id]`)
- 7 тестов: выгорание, стресс, энергия, тип личности (MBTI), границы, перфекционизм, стресс-2
- Прогресс-бар по вопросам
- Результат: круг с % (если `showPercent: true`) или название типа (MBTI)
- Звёздный рейтинг после теста
- Результаты сохраняются в `test_results`

---

## Сертификат (`/certificate`)
- Условия: пройти все уроки ИЛИ 3+ теста
- 3 темы оформления: тёмная, фиолетовая, светлая
- Превью с масштабированием
- Скачивание в PDF (html2canvas → jsPDF)

---

## Админ-панель (`/admin/*`)
Доступ только для `ADMIN_EMAIL` или `role: admin`

| Раздел | Функционал |
|--------|-----------|
| `/admin` | Дашборд: пользователи, заявки, тесты, уроки, рейтинг |
| `/admin/applications` | Список заявок, смена статуса (новая/обработана) |
| `/admin/users` | Все пользователи с прогрессом |
| `/admin/lessons` | CRUD уроков, добавление модулей, сохранение в Supabase |
| `/admin/tests` | CRUD тестов и вопросов, сохранение в Supabase |
| `/admin/tips` | CRUD советов дня, сохранение в Supabase |

## Технологии и инструменты

### Frontend
- **Next.js 16** (App Router) — выбрал за Server Components, встроенную оптимизацию и file-based routing
- **TypeScript** — строгая типизация для надёжности кода
- **SCSS Modules** — изолированные стили, удобная вложенность, переменные для тем
- **GSAP** — плавные анимации счётчиков и элементов при скролле
- **Lucide React** — современные SVG иконки
- **html2canvas + jsPDF** — генерация PDF сертификатов на клиенте

### Backend & Database
- **Supabase** — выбрал за готовую авторизацию, PostgreSQL, Row Level Security и real-time возможности
- **Supabase Auth** — email/password регистрация с подтверждением
- **PostgreSQL** — реляционная БД с 8 таблицами, связями и RPC функциями
- **Row Level Security (RLS)** — политики доступа на уровне БД для безопасности

### Дополнительно
- **Resend** — отправка email уведомлений о новых заявках
- **Vercel** — деплой и хостинг (рекомендуется для Next.js)

## Сложности и решения

**Проблема:** Next.js 16 имеет breaking changes, документация не всегда актуальна  
**Решение:** Изучал официальные гайды в `node_modules/next/dist/docs/`, следил за deprecation notices

**Проблема:** Row Level Security блокировал запросы даже для авторизованных  
**Решение:** Переписал политики RLS, использовал `auth.uid()` правильно, добавил политики для service role

**Проблема:** Генерация PDF сертификатов с кириллицей  
**Решение:** Настроил правильные шрифты в jsPDF, использовал html2canvas для рендера

**Проблема:** Анимации тормозили на мобильных  
**Решение:** Оптимизировал GSAP анимации, добавил `will-change`, уменьшил количество одновременных анимаций

**Проблема:** Переключение тем вызывало мерцание  
**Решение:** Использовал CSS переменные и data-атрибуты, добавил transitions
